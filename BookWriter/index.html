Backup, restore, export, and erase

Portable backup

A backup preserves all supported fields and ordering for later restore. It is a readable JSON file, but it is not encrypted.

Replace from backup

A valid restore shows counts and asks before replacing this browser’s current collection. Invalid files change nothing.

Readable exports

HTML and UTF-8 text exports are independent reading copies. They cannot be restored into the app.

Erase this browser’s memoir

This removes only Life Memoir Writer’s local storage key. It cannot erase downloaded backups or exports.
